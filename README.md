# Velora

Velora is an Android traffic monitoring application that provides real-time congestion notifications
and route guidance using Firebase Realtime Database.

## Features

- Real-time traffic monitoring
- Traffic congestion notifications
- Road construction alerts
- User authentication
- Profile management

## Technology Stack

- Kotlin
- Jetpack Compose
- Firebase Authentication
- Firebase Realtime Database
- Koin
- Material 3

## Requirements

- Android 9 (API 28) or higher
